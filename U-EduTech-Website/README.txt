U EduTech Responsive Website
===========================

1. Open index.html locally to preview.
2. Upload the entire folder to Netlify, or push it to GitHub and enable GitHub Pages.
3. Replace these sample test links with your real HTML pages:
   tests/mat-test-01.html
   tests/sat-science-01.html
   tests/maths-test-01.html
4. Replace the YouTube link and email in index.html.
5. You can add your existing HTML tests inside a /tests folder.

No framework or build step is required.
