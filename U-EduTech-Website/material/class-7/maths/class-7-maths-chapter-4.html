Expressions using Letter-Numbers Expressions using Letter-Numbers

अक्षर-संख्याओं वाले व्यंजक Introduction to letter-numbers and algebraic expressions

📘 अध्याय परिचय 📘 Chapter Introduction

अब तक हमने expressions में मुख्यतः निश्चित संख्याओं का प्रयोग किया है। लेकिन गणित में कई बार किसी अज्ञात या बदलती हुई संख्या को किसी अक्षर से दर्शाया जाता है।

उदाहरण के लिए यदि किसी संख्या को x से दर्शाया जाए, तो उससे जुड़े expressions जैसे x + 5, 2x, x − 3 आदि लिखे जा सकते हैं।

इस अध्याय में हम letter-numbers, algebraic expressions, terms, coefficients, constants और expressions का मान ज्ञात करना सीखेंगे।

So far, we have mainly used fixed numbers in expressions. In mathematics, an unknown or changing number is often represented by a letter.

For example, if a number is represented by x, we can write expressions such as x + 5, 2x and x − 3.

In this chapter, we learn about letter-numbers, algebraic expressions, terms, coefficients, constants and evaluating expressions.

1️⃣ Letter-Numbers क्या हैं? 1️⃣ What are Letter-Numbers?

किसी संख्या को किसी अक्षर से दर्शाने पर उस अक्षर को letter-number के रूप में प्रयोग किया जा सकता है।

यदि किसी संख्या को x से दर्शाया गया है:

x = कोई संख्या
x + 5 = उस संख्या से 5 अधिक
x − 5 = उस संख्या से 5 कम

अक्षर का मान परिस्थिति के अनुसार बदल सकता है।

A letter can be used to represent a number. Such a letter is used as a letter-number.

If a number is represented by x:

x = a number
x + 5 = 5 more than the number
x − 5 = 5 less than the number

The value represented by the letter may change according to the situation.

2️⃣ अक्षर का बदलता हुआ मान 2️⃣ A Changing Value of a Letter

मान लीजिए एक टोकरी में x आम हैं। यदि दूसरी टोकरी में उससे 3 आम अधिक हैं, तो दूसरी टोकरी में आमों की संख्या होगी:

x + 3

यदि पहली टोकरी में 10 आम हैं, तो:

x = 10
x + 3 = 13

यदि पहली टोकरी में 20 आम हैं, तो:

x = 20
x + 3 = 23

Suppose a basket contains x mangoes. If another basket contains 3 more mangoes, the number of mangoes in the second basket is:

x + 3

If x = 10:

x + 3 = 13

If x = 20:

x + 3 = 23

3️⃣ Algebraic Expressions 3️⃣ Algebraic Expressions

जब numbers और letter-numbers को mathematical operations के साथ लिखा जाता है, तो हमें algebraic expressions प्राप्त होते हैं।

x + 7

3x + 5

2a − 4

5p + 2q

इन expressions में letters किसी संख्या को दर्शाते हैं।

When numbers and letter-numbers are combined using mathematical operations, we get algebraic expressions.

x + 7

3x + 5

2a − 4

5p + 2q

The letters in these expressions represent numbers.

4️⃣ Terms क्या हैं? 4️⃣ What are Terms?

किसी algebraic expression के अलग-अलग भागों को terms कहा जाता है। Terms सामान्यतः + या − चिन्हों से अलग होते हैं।

3x + 5

Terms → 3x और 5
5a − 7b + 3

Terms → 5a, −7b, 3

The separate parts of an algebraic expression are called terms. Terms are usually separated by + or − signs.

3x + 5

Terms → 3x and 5
5a − 7b + 3

Terms → 5a, −7b, 3

5️⃣ Coefficient 5️⃣ Coefficient

किसी variable या letter के साथ गुणा होने वाली संख्या को उसका coefficient कहते हैं।

5x

x का coefficient = 5
12a

a का coefficient = 12
x

x का coefficient = 1
यदि किसी letter के आगे कोई संख्या नहीं लिखी है, तो coefficient 1 माना जाता है।

The number multiplied with a variable or letter is called its coefficient.

5x

Coefficient of x = 5
12a

Coefficient of a = 12
x

Coefficient of x = 1
When no number is written before a letter, its coefficient is 1.

6️⃣ Constant क्या है? 6️⃣ What is a Constant?

ऐसी संख्या जिसका मान नहीं बदलता, उसे constant कहते हैं।

3x + 7

x → variable / letter-number
3 → coefficient
7 → constant
5a − 12

5 → coefficient
a → letter-number
12 → constant

A number whose value does not change is called a constant.

3x + 7

x → variable / letter-number
3 → coefficient
7 → constant
5a − 12

5 → coefficient
a → letter-number
12 → constant

7️⃣ समान Terms 7️⃣ Like Terms

जिन terms में समान letter-number का समान घातांक हो, वे like terms कहलाते हैं।

3x और 7x → Like terms

5a और −2a → Like terms

4x और 4y → Unlike terms

Like terms को जोड़ या घटाया जा सकता है।

3x + 7x = 10x
8a − 3a = 5a

Terms with the same letter-number and same power are called like terms.

3x and 7x → Like terms

5a and −2a → Like terms

4x and 4y → Unlike terms

Like terms can be added or subtracted.

3x + 7x = 10x
8a − 3a = 5a

8️⃣ Expression का मान ज्ञात करना 8️⃣ Evaluating an Expression

यदि किसी letter-number का मान दिया गया हो, तो उस मान को expression में रखकर expression का value निकाला जा सकता है।

यदि x = 5, तो:

x + 7
= 5 + 7
= 12
यदि a = 4, तो:

3a + 2
= 3 × 4 + 2
= 12 + 2
= 14

If the value of a letter-number is given, substitute that value into the expression and calculate its value.

If x = 5:

x + 7
= 5 + 7
= 12
If a = 4:

3a + 2
= 3 × 4 + 2
= 12 + 2
= 14

9️⃣ शब्दों से Algebraic Expression बनाना 9️⃣ Writing Algebraic Expressions from Words

किसी संख्या से 5 अधिक
→ x + 5
किसी संख्या से 7 कम
→ x − 7
किसी संख्या का 3 गुना
→ 3x
किसी संख्या का आधा
→ x/2
किसी संख्या का 4 गुना और 3 अधिक
→ 4x + 3
5 more than a number
→ x + 5
7 less than a number
→ x − 7
Three times a number
→ 3x
Half of a number
→ x/2
Four times a number and 3 more
→ 4x + 3

🔟 Patterns और Letter-Numbers 🔟 Patterns and Letter-Numbers

कई number patterns को algebraic expressions की सहायता से लिखा जा सकता है।

2, 5, 8, 11, 14, ...

हर बार 3 जोड़ा जा रहा है।
अगला term = 17

यदि पहला term किसी letter से दर्शाया जाए, तो pattern के terms को expression के रूप में भी लिखा जा सकता है।

Many number patterns can be represented using algebraic expressions.

2, 5, 8, 11, 14, ...

3 is added each time.
Next term = 17

If a term is represented using a letter, other terms can be expressed using algebraic expressions.
